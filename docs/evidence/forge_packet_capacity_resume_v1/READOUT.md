# FORGE_PACKET_CAPACITY_RESUME_V1

Технический ремонт готов к независимому delivery review и принятию версии.
Реальный научный Critic ещё не запускался: он следует после merge принятого кода.

Общий resolver разделяет рекомендацию рабочей выдачи и ресурсную защиту.
Mandatory priors и material restrictions сохраняются полностью, включая рост
сверх прежних64 записей/64KiB. Optional recall не расширяется до всего архива.
Полный parent измеряется после сборки. CLI, Fast Lane и cold context readers
ограничивают фактическое чтение. Revision, runner-up, frozen read и historical
challenger используют сохранённый контракт; новые настройки не пересобирают
старую память. Новый helper включён в execution code binding.

Адресные доказательства и воспроизводимые команды: validation.json. Fixtures
синтетические; Critic replies внутри lifecycle test механические, без научных
полномочий. Исходные неуспешные проверки не скрыты.

Девять именованных recovery-файлов закреплены в существующей локальной области
операции с исходными hashes (recovery.json). Data root не копировался.
В исходном checkpoint MAIN=1; реальных научных команд в ремонте0,
candidate/session ещё не создавались. Свежий readback реального Store следует
после принятия версии. Сохранённый Result SHA:
39028f4afacd8c0af9575ee37bf0447be10c19f147fda56bcb62ce9114d68c87.

После exact-head CI/readiness требуется отдельная owner merge phrase.
После принятия версии уже разрешено: выбрать её, прочитать resolver/состояние,
сохранить candidate на прежнем результате, freeze, передать полный packet
на независимый Critic и исполнить native review/classification transition.
Новый MAIN для ремонта запрещён. Если resolver потребует дальнейшего научного
поиска, вернуть его точную операцию, не фабрикуя owner_final.

Scout остаётся adaptive advisory context; история не независимый OOS.
PRICE_RELATIVE_PROXY не подтверждён source event times: reference/exit UNKNOWN.
Следующий независимый holdout должен быть защищён и от Forge, и от Scout.
Ни SOL/context product adoption, ни ExperimentSpec execution не разрешены.
