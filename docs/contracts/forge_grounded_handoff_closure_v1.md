# Fresh grounded handoff closure V1

Owners: `hfic_grounded_discovery.card_claim_scope/validate_fresh_card_scope`,
`hfic_research_scope`, `hfic_session` and `hfic_preflight`. This is a transport
and dependency repair, not a new scientific criterion or experiment engine.

An ordinary selected card bound to a saved look declares `population`,
`decision_timestamp`, `target`, `estimand` and `explanatory_condition` as
top-level nonempty scalar fields. `target` is the exact supported machine
target label, not the prose `primary_y`. Declare `representation_scope` when
the look binds it. A list-scoped look also requires the exact
`research_scope_rule_sha256` and `research_scope_statement`. A working card
example is `tests/fixtures/forge_grounded_handoff_closure_v1/flat_card.json`.
`proposed_method`, `actor_counterparty`, `primary_x_family`, `primary_y` and
`horizon_notional` are the actual draft fields; prose synonyms are not parsed.

Nested-only fields receive `CANDIDATE_SCOPE_FIELDS_REQUIRED`, including the
missing top-level names, candidate ordinal and next action. Agreeing nested
copies are non-authoritative authored bytes; conflicting copies receive
`CANDIDATE_SCOPE_FIELDS_CONFLICT`, malformed copies `CANDIDATE_SCOPE_INVALID`.
Move only the agent's already-authored values before the first persistence.
This correction creates no look, nomination or `REVISE_ONCE`. Never infer a
missing intent from a favorable result. Unmeasured ideas and historical
readers are not forced to invent a target. A complete different question
keeps `LOOK_SCOPE_NARROWER`; a population/decision contradiction still refuses.

Primary and runner-up packets share the existing projection builder and
carry their own scalar axes and `claim_form`. Runner-up evidence is bound
independently, not borrowed by similarity. Wording revision uses that builder
and locks every bound semantic axis and predictive/causal form, separately
from the definition hash. Historical bytes and terminal judgements are never
rewritten. Unsupported advancement returns a technical gap.

Authored `available_data_bindings` may contain typed frozen-input objects.
The shared selected-candidate builder encodes each such object as canonical
JSON in the Critic's existing string-array narrative transport. Decoding must
recover every field and value; existing strings remain byte-identical. A
malformed outer shape or unsupported scalar remains schema-invalid. This
projection does not turn narrative strings into resolver bindings. The
persisted draft, typed `temporal_recipe.frozen_input`, ExperimentSpec 1.3
`data_bindings`, candidate definition and scientific look remain unchanged.
An orphan generated draft may resume only through the existing verified
`prefreeze_capability_repair`, retaining its original slot/reservation/accounting.

Before a fresh generated draft, frozen session or zero-candidate terminal can
write, the inline context/digest must agree and the exact context blob and
committed artifact must exist under that ResearchStore root. Existing
`verify_forge_context_packet` supplies the verification, with an exact recheck
under the existing writer lease. `--no-auto-commission` stays read-only.
Missing/corrupt context is a technical refusal, writes no candidate/session/
slot, refunds no spent discovery look and creates no scientific negative.
For a new input, run normal persistent preflight and bind its new verified
receipt to the same saved question/look. For historical readback, restore the
exact saved dependency; a new preflight does not repair old history.

New tier progress carries
`freeze_worthy_semantics=CALLER_ROUTING_HINT_NOT_SCIENTIFIC_VERDICT` beside the
unchanged boolean/action. `false` is not a standalone KILL reason;
`READY_TO_FREEZE` is not hypothesis confirmation. Support, missingness, PIT,
grounding and independent scientific critique retain their own authority.
Saved numerical results are not recomputed to add this interpretation.

Canonical query ingress is specified by
`forge_list_aware_research_scope_v1.md`. Same-data DocumentRunner execution
proves a frozen technical replay, not chronological confirmation, alpha,
scientific acceptance, StrategyVersion activation or trading authority.
Run research on a stable code checkout; update/rebase after its lifecycle.
The Git write fence and scientific/owner budgets are unchanged.
