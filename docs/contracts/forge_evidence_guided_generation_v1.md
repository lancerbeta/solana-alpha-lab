# FORGE_EVIDENCE_GUIDED_GENERATION_V1

Ordinary Forge provides a small, source-bound view of admissible research
history. Full archive checks remain independent of that view. It helps a
generator choose and express a discriminating question; it grants no new
scientific exposure, collection, trading or promotion authority.

Primary path: OPPORTUNITY_EPISODES BASE and already admitted
NORMALIZED_TRAJECTORY_EPISODES_V1. Legacy/control compatibility is preserved.
Public owners are preflight, prior, freeze and the existing run lifecycle.
The selector in hfic_generation_context owns projection only.

| Contract | Fresh primary | Historical/control |
|---|---|---|
| Critic input |1.5, every1.4 grounding floor|1.0–1.4, unchanged meanings|
| Research memory |1.1 BOUNDED_WORKING_SET|1.0 complete full snapshot|
| Generation context |1.0, this policy revision|Absent where historical|

The initial view contains at most8 capsules. Critic memory contains at most64.
The complete serialized Critic parent, including all metadata, is at most65536
bytes. Mandatory source overflow refuses before durable session publication;
optional tails may be omitted with exact counts and source locators. Selection
completeness never asserts archive completeness.

Existing eligibility owns own-session outcomes, quarantine, lineage and both
research clocks: effective_at and first_reliable_available_at. The first saved
preflight binds the research cutoff. Market research_memory_as_of is a separate
clock. Same-run admitted results are explicit grounded evidence, not a refresh
of initial priors. Fresh1.5 research events become available at persistence;
session_started_at retains the initial cutoff. Legacy recorded clocks stay
unchanged.

Existing full-scope prior and typed ledger guards execute before ranking. A
successful safety receipt binds their actual relations, scope, cutoff and
inventory. Supplied prior/result refs, emitted initial priors and already typed
material restrictions are mandatory. Selection then uses declared structural
axes, diversity and text. Outcome sign does not rank records. Narrative is
never parsed into a scientific scope or closure.

Source detail retains source refs, own-session verdict, interpreted failure
class, recorded finding and explicit NOT_RECORDED gaps. Saved descriptive
findings require current role/holdout/cohort/file/schedule admission plus
durable calculation integrity. They are read, not recomputed. Critic objections
remain MODEL_REVIEW_ONLY. Neither authored text nor a KILL label closes a family.

## Bound prior detail

Use the CLI with the explicit authorized data root, then:

```text
prior --context-view --preflight-receipt preflight.json --selection-query-sha256 <bound-query-sha> --source-ref <exact-HYP-or-record-ref>
```

This existing `prior` mode is read-only: no store commissioning, reservation,
profile change, value calculation or look. The receipt owns the post-context
inventory; its working view records the source inventory before that append.
An old receipt after a writer returns GENERATION_CONTEXT_STALE_STORE_BINDING.
Persistent preflight may reissue a read binding only after verifying the same
eligible source fingerprint, cutoff, selection, query and capsule bytes.
GENERATION_CONTEXT_MATERIAL_SOURCE_CHANGED refuses a changed material source.
A consulted detail must be named in the authored card's prior_work_refs;
freeze carries that mandatory source into Critic memory.

Metadata reads use `discovery-binding --collection OPPORTUNITY_EPISODES` and
`discovery-coverage --collection OPPORTUNITY_EPISODES`. Coverage is metadata-only;
joint support remains NOT_MEASURED_METADATA_ONLY. Current query grammar comes
from `forge_context_packet.episode_query_capabilities.query_authoring_contract`. Canonicalize the
authored query through `research-scope-resolve --spec query.json` before use.
Preview and MAIN keep their existing ordinary-operation admission/accounting.
The emitted query contract includes feature_node and predicate_node grammar.
Feature name is an authored alias; all[].feature repeats that alias. Comparisons
use the existing gt/gte/lt/lte/between enums, never symbolic operators. List
diagnostic_slices belongs at query top level, not inside research_scope.

## Ordinary operation ingress

This is the existing request accepted by hfic_ordinary_operation.record_operation
through public discovery-preview/discovery-execute `--operation`. It is ingress
grammar, not a new schema, operation, quota or scientific recipe. Values below
are placeholders; substitute only the already authorized request, exact current
preflight fields and independently authored canonical query.

```json
{
  "owner_request_text": "<verbatim authorized question>",
  "owner_focus": "<preflight.owner_focus>",
  "journal_scope": "<preflight.search_key_sha256>",
  "market_evidence_epoch_sha256": "<preflight.market_evidence_epoch_sha256>",
  "requested_completion": "LIMITED_RESULT",
  "owner_cap": {"main": 0, "adaptive": 0, "preview": 0},
  "question_text": "<fixed outward question>",
  "spec": {}
}
```

Replace owner_cap zeros with the exact existing authorized ceilings; this
example grants zero. Replace spec with the unchanged canonical_query object
returned by research-scope-resolve. MAIN=1 requires an explicit valid spec.
LIMITED_RESULT stops after the admitted bounded result; it does not claim a
scientific terminal. Reuse the returned operation_sha256 for continuation.
Changing code, prompt or process does not refund exposure or mint a new slot.
Use `preflight.evidence_surface_mode` in the independently authored candidate
scope. The verified ingress may fill an omitted mode; a conflicting supplied
mode is `LOOK_SCOPE_CONTRADICTION`. Population is not a substitute for mode.
No guessed hashes, new cycle, parent link or representation fields are needed
for an ordinary BASE request. Legacy, additional-cycle and representation
routes retain their existing stricter contracts.

## Consumer and recovery boundaries

Scientific core precedes transport: observable uncertainty, competing mundane
explanation, discriminating prediction, minimum supported falsifier and next
decision. PREDICTIVE does not require an invented actor or causal story.
Unsupported operators remain exact capability gaps. A supported recipe is not
proof of information value, statistical power, executable economics or alpha.

Freeze reuses the lossless PR388 card projector. Primary and runner have their
own full guard, working view, grounding and parent byte bound. Claim revision
keeps mechanism/scope/look locks and reruns full prior safety. Saved packets
are append-only and are never silently rebuilt by a future selector. Critic
receives only the frozen packet and public method/schema; missing material
evidence is a typed blocker, never permission for archaeology.

Legacy packets/snapshot hashes and scientific charges are immutable. New1.5
sessions require a compatible reader; an unsupported old writer must stop and
retain the exact packet locator. Capability drift and readback are different
from new market evidence. Recovery follows the existing generated-draft,
session and accounting owners, with no repeated generation or new look.

Evidence and verdicts live in docs/evidence/forge_evidence_guided_generation_v1.
Synthetic implementation, safety, formulation, comparison and delivery are
separate axes. Market alpha, chronology and live economics are NOT_EVALUATED.
