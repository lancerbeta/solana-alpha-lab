# HORIZON_SCOPED_SCIENTIFIC_ELIGIBILITY_V1

Scientific N is X300-valid `X_ELIGIBLE` (`base_x_population.n`). Outcome
missingness is coverage against that denominator. It does not shrink N and
can only fail-close an experiment into the existing data/science-option
route (`PASS_DATA_OPTION_REQUIRED`).

`COMPLETE` means every `required_outcomes` row has a resolved observation
state, including `CENSORED_LATE` / `MISSING_TYPED`. It is not a
complete-case population.

Historical selection receipts stay byte-immutable
`FULL_LIFECYCLE_COMPLETENESS` caveats. A valid receipt does not globally
STOP `START_NEW_SESSION`. Auto-veto fires only when required Y points
exactly equal the bound schedule Y set. An unusable/mismatched receipt is
`SELECTION_RECEIPT_INTEGRITY_INVALID` / `REBIND_SELECTION_RECEIPT_IDENTITY`,
not a selection veto and not a collection order. A too-wide Y set is
`FULL_LIFECYCLE_SELECTION_SCOPE` / `NARROW_REQUIRED_OUTCOMES_OR_STOP`.

CONTROL / NT floor use consume-time `base_x.n`. NT motif `M` is unchanged.
`forge-control-ready` may still report lifecycle `yield_eligible` when the
canonical release cannot be projected; CONTROL preflight then fail-closes
until `base_x` is computed.

This atom does not run Forge and does not perform sealed C1 semantic
acceptance. That read-only acceptance is the next atom after merge.

Terminal of this atom: reviews + exact-head CI + merge-readiness / owner
phrase. Not canonical DONE, not alpha, not C1 accepted.
