first unattended remote runtime. Activate earlier if a second human or
external agent must operate the system, or if two task cycles repeat the same

decision index, dataset/replay examples, operator runbooks for start/stop,
backup/restore and incident recovery, and one update check in normal delivery.

design are separate decisions.
